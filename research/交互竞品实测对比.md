## 1. 同花顺问财：把「金融能力」做成 Skill 给 Agent 装

这是本次调研里对我们威胁最大的一项——**它已经把“Agent 接入”做成了货架商品**。

### 1.1 AI 使用与 Agent 接入

入口：左侧导航 **SkillHub**（<https://www.iwencai.com/skillhub>），页面抬头就是 `问财 × OpenClaw` 联名，标题「全球最大的金融投资AI技能库」，副标写着“兼容 OpenClaw 等主流平台”。

货架内容（官方出品 6 张卡）：

| 技能 | 一句话 |
|---|---|
| 公告搜索 | A 股/港股/基金/ETF 公告查询，覆盖定期报告等 |
| 研报搜索 | 主流投研机构研报，取分析逻辑、评级、目标价 |
| 新闻搜索 | 财经资讯搜索引擎，官媒 + 财经媒体 + 垂直站 |
| 指数数据查询 | 上证/沪深300/创业板/恒生/纳指行情 |
| 问财选板块 | 估值、资金流向、涨跌幅、板块类型多条件筛板块 |
| 公司股东股本查询 | 股本结构、股东户数、前十大股东、实控人 |

### 1.2 装一个技能要点几下（实测点击序列）

1. 打开 `iwencai.com/skillhub`；
2. 点任意官方技能卡（我点的是「公告搜索」）；
3. 弹出安装弹窗，顶部有来源标签（`来源：社区`）与**安装方式双页签**：`Agent 用户` / `CLI 用户`；
4. 页签下只有一句话：“将以下 Prompt 复制到您的 AI 助手中，即可完成技能安装”，旁边一个 **复制** 按钮；
5. 底部注明适用范围：“Claude、OpenClaw、MaxClaw、WorkBuddy、QClaw、KimiClaw 等 AI 助手”；
6. 未登录时叠一层遮罩：“请先登录后继续安装 / 安装与配置仅对登录用户开放”→ `立即登录`。

> **这就是它的全部接入成本：复制一段 Prompt，粘进你正在用的 AI 助手。** 没有本地 Runner、没有端口、没有握手协议、不用装 CLI。

### 1.3 AI 选股本身的交互

点击序列：左侧 `AI选股` → 中央大输入框（占位符“请输入您的筛选条件，多个条件用分号隔开”）→ 输入自然语言 → 回车 → 跳转 `/screener/result?w=…&querytype=stock`。

结果页骨架（我们的 IP 只看到骨架，数据被 403 挡住）：

- 顶部回显问句，右侧 `复制/收藏`；
- 一行条件 chips：`A股` / `我的自选` / `条件选股` / `我的收藏`——**解析出的条件可见、可改、可增删**；
- 结果表：表头可排序，可拖动换列，可“筛选表头”；
- 勾选股票 → 加入自选 / 加入板块；
- 一键导出表格。

> 值得抄的点：**AI 解析出的条件必须显式摆出来**，用户才敢信。我们目前的事件台账只有“结论”，没有“它把什么当成了条件”。

## 2. Alpha Arena：把「模型推理」做成一级内容

线上 <https://www.alphaarena.ai/>，实时榜，不需要登录。

### 2.1 结构

`LIVE | LEADERBOARD | MODELS | BLOG | ABOUT` + 顶部 Aggregate Index 多标的叠图（TSLA / NDX / NVDA / MSFT / AMZN / GOOGL / PLTR）。

### 2.2 榜单列（10 列，可排序）

`RANK / MODEL / ACCT VALUE / RETURN % / TOTAL P&L / FEES / WIN RATE / BIGGEST WIN / BIGGEST LOSS / SHARPE / TRADES`

模型名带**人设后缀**，这是它最聪明的设计：

- `GROK-4.20 - 3: SITUATIONAL AWARENESS`
- `GPT-5.1 - 4: MAX LEVERAGE`
- `DEEPSEEK-CHAT-V3.1 - 2: MONK MODE`

同一个模型在不同人设下排名完全不同（GROK 一个榜第一、一个人设第 6）。**它比的不是“模型”，是“模型 + 人设”这一对。**

### 2.3 每个模型下面三块折叠（这是最该偷的）

```
▶ USER_PROMPT        ← 它当时收到的指令/上下文
▶ CHAIN_OF_THOUGHT   ← 它当时的思考
▶ TRADING_DECISIONS  ← 它当时的动作
```

默认折叠，点开即看原文。配上 `MODELCHAT` 流（如 `GEMINI-3-PRO | New Baseline 12/06 05:51:07 — I'm betting on a breakout in NVDA…`）。

> 我们的复盘页现在是「结论 + JSON」，缺的正是**指令 → 思考 → 动作**这条三段链的并列呈现。

## 3. TraderHarness：本机跑起来后的真实交互

### 3.1 怎么起来

```powershell
python -m venv th-venv
th-venv\Scripts\python -m pip install "traderharness[ui]"
th-venv\Scripts\traderharness ui --port 8011
# TraderHarness UI: http://127.0.0.1:8011
```

### 3.2 首屏（工作台）

左栏五项：`工作台 / 智能体 / 实时运行 / 回测结果 / 智能体对比`，右上角常驻两枚状态：`● 系统就绪`、`严格时序遮罩`。

主体是「运行概览」四张卡：

| 卡 | 实测值 | 意义 |
|---|---|---|
| 市场数据 | **缺失** | 直接告诉你没数据 |
| 模型服务 | 仅可回放 | 没 Key 也能看 |
| 智能体卡片 | 8 | 内置 8 个策略 |
| 已完成回测 | 0 | 本地结果工件数 |

下面就是「新建实验」表单：开始日期 / 结束日期 / 遮罩种子 / 执行智能体（8 张卡，各带风格标签与 `deepseek-v4-pro`）/ 强制遮罩 / `开始回测`。旁边一个更醒目的按钮：**`运行免密演示`**。

### 3.3 点「运行免密演示」之后

1. 直接跳 `http://127.0.0.1:8011/live?run=d1a6324f…`；
2. 页面标题「回测控制室」，副标题「运行 d1a6324f3001 · 带日志的 WebSocket 事件流」；
3. 三张状态卡：`事件连接 离线` / `事件数量 3` / `执行者数量 1`；
4. 中间是像素办公室画布（研究工位 / 风控执行台 / 策略会议室）；
5. 右侧「实时绩效 · 净值与进度」+ 事件速率（0.3 条/秒 · 近 10 秒）；
6. 右下「决策事件流」带 6 个筛选 chip：`全部 / 阶段 / 工具 / 订单 / 错误 / 思考`，外加一个 **`暂停滚动`** 开关；
7. 事件行：`#3 · 运行时 / Error`、`#2 · 运行时 / 加载数据`、`#1 · 运行时`。

### 3.4 失败态（重要）

因为我没下数据集，整页顶部出现一条红色横幅，**原样打出 Python 异常**：

```
回测失败：Canonical daily dataset not found at C:\Users\J\.traderharness\dataset\daily.parquet.
Run `traderharness data download --full`.
```

> 这是“零 Key 三步上手”路径上的断点：文案把内部路径和 CLI 命令直接甩给了用户。
> **对我们的启发**：训练场必须内置“数据未就绪 / 模型未配置 / 预算耗尽”三种**可动作**的阻断态，而不是抛异常。

### 3.5 数据为什么跑不出来

```
traderharness data list
  [ ] a50-2023   [ ] a50-2024   [ ] test-fixture

traderharness data download -d a50-2024
→ 401 RepositoryNotFound: huggingface.co/api/datasets/HephaestLab/a50-2024

traderharness data download -d test-fixture
→ Downloaded to: ~/.traderharness/datasets/test-fixture   （实际目录为空）
```

所以**在干净机器上，没有 HF 凭据就跑不出一次成功回测**。这点写在这里，是为了说明：他们“零凭据体验”的承诺目前只在有数据预热的环境里成立。

### 3.6 其余三页

- **`/results` 结果资料库**：`排序：最新优先 / 收益率 / 交易天数`，列表行可勾选（勾 2–4 个去叠加对比），失败行也留在列表里并标 `失败`；
- **`/compare` 智能体横向对比**：开始/结束日期 + 遮罩种子 + 选 ≥2 个 agent → `运行对比`；下方还有“已完成回测？去结果资料库勾选 2–4 个结果工件，即可叠加权益曲线”的空态引导；明写「确定性排名 · 横向对比不等于多角色委员会」；
- **`/agents` 智能体注册表**：8 张卡，每张有风格标签（逆向/事件/趋势/质量/量化/行业/价值）、风险档位（保守/均衡/进取）、持仓周期、**工具数量**、**单票上限**、一句策略描述，右上 `新建智能体`。

## 6. 我们该改什么（按投入产出排序，直接对应代码）

### P0 — 这周就能改，改完手感立刻不同

**① 台账加「暂停滚动」显式开关 + 事件速率**

- 现状：`src/components/ledger/DecisionLedger.tsx` 只做了隐式自动跟随 + 滚上去出「N 条新事件↓」；
- 对标：TraderHarness 的 `暂停滚动` 是**看得见的按钮**，还配 `事件速率 X 条/秒`；
- 做法：加一个 `autoFollow` 状态 + 按钮，速率用最近 10 秒事件数 / 10 计算，显示在页脚。

**② 三种可动作的阻断态**

- 现状：`src/store/RunProvider.tsx` 只有 `active/paused/aborted`；数据永远是“就绪”；
- 对标：TraderHarness 首屏直接显示「市场数据 缺失」，但失败后给的是异常原文（反面教材）；
- 做法：`RunState` 增加 `blocked?: { reason, actionLabel, actionHref }`，训练场在数据未就绪/预算耗尽/模型未配置时，**顶部黄条 + 一个能点的修复按钮**，而不是红字报错。

**③ 接入页要有“可复制的真实产物”**

- 现状：`src/routes/ConnectPage.tsx` 三步是假流程（安装→Runner→握手），复制按钮复制的是 `/install openoutcry-skill`；
- 对标：问财两个页签 `Agent 用户 / CLI 用户`，核心动作是**复制一段真正的 Prompt** 粘进任何助手；
- 做法：保持三步叙事，但第一步产物变成**一段可复制的接入 Prompt（含 runner 地址占位、权限边界、动作格式）**，并给出“粘到 Claude/Cursor/自研框架”的具体位置；CLI 页签保留原命令。这样它从“演示”变成“能真用”。

**④ 批准后 3 秒可撤销**

- 现状：`src/components/proposal/ProposalTicket.tsx` 批准即 `submitted`，只能等撮合；
- 对标：四家**都没有**。这是我们的差异点，做出来就是记忆点；
- 做法：`approve` 后进 `pending-undo` 状态，toast 里带「撤销」，3 秒后自动转 `submitted`；台账对应行高亮。

**⑤ 事件详情改成三段折叠**

- 对标：Alpha Arena 的 `USER_PROMPT / CHAIN_OF_THOUGHT / TRADING_DECISIONS`；
- 做法：`src/components/dialogs/DetailDialog.tsx` 从“一堆 dt/dd + JSON”改为同样三块折叠，第一屏只放结论与证据编号。

### P1 — 需要新页面/新状态

**⑥ 结果资料库 + 多选叠加对比**

- 现状：`/review` 只有当前一次运行；`/compare` 在原型里没有；
- 对标：TraderHarness `/results`（勾选 2–4 个工件）+ `/compare`（空态引导去勾选）+ Alpha Arena 10 列排序榜；
- 做法：新增 `src/routes/ResultsPage.tsx`：列表（含失败行）→ 勾选 → 底部浮出「对比 N 个」→ 进 `ComparePage` 叠权益曲线 + 指标表。列表列参考 Alpha Arena：收益、相对基准、夏普、回撤、胜率、交易数、费用。

**⑦ Agent 卡补四个字段**

- 对标：TraderHarness 卡上有 风险档位 / 持仓周期 / **工具数量** / **单票上限**；
- 做法：`src/data/agents.ts` 的 `AgentMeta` 加 `riskLevel / holdPeriod / toolCount / maxPositionPct`，`StudioPage` 卡片展示。这四列直接回答“这个 Agent 有多猛”。

### P2 — 明确不做

- 像素办公室：TraderHarness 用它做氛围，但实测它占了首屏 55% 高度且对判断毫无帮助；
- 排行榜公开下注：合规与数据门槛都不在 FYP 范围内。
