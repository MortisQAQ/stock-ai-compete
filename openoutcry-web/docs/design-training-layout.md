# 训练场版面：VSCode 式三栏 + 移动端助手页

> 适用：`openoutcry-web/src/routes/TrainingPage.tsx`　｜　状态：已落地（2026-10-29）
> 一句话：**桌面上把「跟 Agent 说话」「看这一单」「换任务」分成三块并排；手机上把说话那块收进一个能推出来的页面。**

---

## 1. 信息架构

一个训练任务 = 把一段时间窗内的交易工作委托给某个 Agent 或 Agent 团队。
围绕「任务」这个对象，界面被拆成三种读法，各自独立成栏：

| 栏 | 内容 | 回答的问题 | 宽度 |
|---|---|---|---|
| 左 · 会话 | 与当前 Agent / 团队的对话流（AGENT 思考 / TOOL 工具 / ORDER 提议 / HUMAN 人工 / ERROR 异常），逐条带序号与模拟时间；底部是「人工插话」输入区 | **它在想什么、我刚说了什么？** | 320px（300–360） |
| 中 · 工作台 | 四格结算表头（净值 / 净收益 / 现金 / 持仓市值）+ 仪器脊 + 审批票 / 账户 / 持仓 / 明细页签 / 运行状态 | **这一单怎么处理？** | 自适应（800px @1440） |
| 右 · 任务 | 训练任务列表：任务名、委托对象、时间窗、状态、进度（几条决策 / 几笔成交） | **我在哪些任务之间切换？** | 256px（240–280） |

三个栏头都是同一套等宽大写微标签（`label`），栏与栏之间只留 1px 墨线。
整个工作台高度 = 视口高 − 走带 − 报头，**内部滚动，页面不出纵向滚动条**。

### 1.1 为什么这么分

- **时间轴 × 对象 × 范围**：对话流是「时间轴」（不可改写的顺序），工作台是「对象」（这一单、这个账户），任务列表是「范围」（这一段时间委托给了谁）。三者维度互不重叠，并排才不会互相打断。
- **左栏用台账语义而不是聊天气泡**：原型里每条消息本来就是一条 `RunEvent`（有 id、kind、at、meta），所以左栏直接复用决策台账的读法——序号在左、类型 chip、事件名、正文。这样「AI 说了一句话」和「系统记了一笔」长得一样，谁也不能偷偷改历史。
- **批准 / 拒绝只在中栏**：左栏输入框是「人类插话」，只追加带时间戳的指导；同一个动作绝不出现两次（原页面在左中右各有过一次决策入口，这是本轮主要收敛点）。
- **右栏把「任务」变成一等公民**：原页面只有一个隐含的「当前运行」，切任务这件事不存在。现在任务列表是可点的主导航，切换后中栏换成该任务的台账。

## 2. 桌面规则（≥1100px）

```
┌ 走带 28 ─────────────────────────────────────────────┐
├ 报头 59 ─────────────────────────────────────────────┤
│ IDX │ 会话 320 │ 工作台 自动 │ 任务 256 │
│ 64  │          │ 表头 + 脊     │          │
│     │ 滚动区    │ 滚动区（唯一主滚动）│ 滚动区    │
│     │ 输入区固定 │              │ 说明固定  │
└─────┴──────────┴──────────────┴──────────┘
```

- **高度推导**：走带 28 + 报头 59 = 87px；`.page` 的 `padding-top`（20/34）+ `padding-bottom`（90）用负 margin 抵消，所以工作台高度恒为 `100dvh − 87px`，页面 `scrollHeight` 恰好等于视口高。
- **左栏固定脚**：输入区 `mt-auto`，消息区 `flex-1 overflow-y-auto`，所以输入框永远在屏内。
- **中栏**：表头（`.band`）与仪器脊是静态的，只有下面的任务本体滚动；审批票贴住滚动区顶部（用 `-mt-3.5` 抵消票据自带的间距）。
- **右栏**：列表 `overflow-y-auto`，底部「任务 = 委托给…」的说明是固定页脚。
- **左侧 INDEX 列收窄成 64px 编号窄条**（`SideNav` 在 `/training` 下只渲染编号 + `sr-only` 名称，`AppShell` 把 `.shell` 的网格列宽换成 `64px minmax(0,1fr)`）。其余五个路由的 DOM 与宽度完全不变。这是「像 VSCode 活动栏」与「1100px 下三栏还能用」之间的唯一解：不动的话 1100px 时中栏只剩约 296px。
- 窄屏补偿：视口 <1280px 时四格表头自动折成 2×2；<1280px 时账户 / 持仓两张卡改单列。

## 3. 移动规则（<1100px，重点看 390×844）

- **主屏 = 任务视图**：任务名 + 状态印章 + 时间窗 + 委托对象 → 一排可横滑的任务按钮 → 四格表头 + 仪器脊 → 回放 / 更多 → 中栏核心内容（审批票优先）→ 页脚。沿用原有 `.mnav`，不新增底部导航。
- **AI 助手 = 可拉起的独立页**：右下 64×64 朱砂圆钮（图标 + 「助手」），点击后全屏页从下方推入。
  - 页头：「会话 · 连接正常」+ Agent 名 + 44×44 关闭按钮。
  - 内容：与桌面左栏**同一份** `ConversationPane`（同一事件流、同一个输入区），不存在两套对话。
  - 关闭方式三种：关闭按钮、ESC、浏览器后退（打开时 `history.pushState` 压一条记录，后退即关闭；关闭时若是我们自己压的记录就走 `history.back()`）。
  - 打开时锁 `body.overflow`；焦点进入关闭按钮，关闭后归还给浮动按钮；Tab 在页内循环。
  - 实现上不新增路由，避免动 `App.tsx` 的路由表。
- **触控**：训练场页自有的可点元素一律 ≥44×44（浮动按钮 64、关闭 44、发送 44、任务按钮 44、步进器 44、页签 44、审批按钮 44）。

## 4. 无障碍与实现约束

- 三段内容各有 `aria-label`（Agent 会话 / 训练任务工作台 / 训练任务），栏头用 `h2`，页面唯一 `h1` 是 `sr-only` 的「训练场 · {任务名}」。
- 任务列表是 `nav` + `button`，当前项 `aria-current="page"` + 朱砂 3px 左侧竖线（不靠颜色单独承载状态：同时有 Badge 文字）。
- 对话流对读屏只播报最新一条（`sr-only` + `aria-live="polite"`），避免整段重放。
- 焦点环沿用全局 `:focus-visible`（朱砂 2px），组件内没有叠 ring，也没有 `outline: none`。
- 颜色全部走令牌（`--plate-*` 只出现在左栏漆板与仪器脊）；纸面卡片里不出现漆板专用浅色文字（档案视图的类型标签因此从 `.chip` 换成 `Badge outline`）。

## 5. 取舍（审阅重点）

1. **任务实体是我猜的**：`src/store/trainingTasks.ts` 里定义 `TrainingTask`（id / name / assignee{kind,name,members} / startAt / endAt / windowLabel / status / live / decisions / fills / archive）。store 里没有这个实体，四个任务中只有一个（`task-live`）由 run/events/trades 实时派生，其余三个是冻结的 mock 档案。接真实数据时只需替换 `trainingTasksOf`。
2. **切到非当前任务 = 只读档案**：原型里没有多任务台账，所以非当前任务展示「任务档案 / 关键决策节选 / 成交」三张纸卡，并明确标注「只读 · 原型数据」，不假装能继续跑。
3. **移动端折叠了标签**：仪器脊在移动端只保留「资料时点 / 轨迹完整性」两条，其余收进任务页脚，避免一屏堆两个信息块。
4. **浮动按钮会盖住内容**：这是 FAB 的固有代价（截图里正好压在提案操作行上）。选择保留，因为辅助页是高频入口；如果要消除，需要把审批票改成吸底操作条，那是下一轮的事。
5. **两张 DOM 树**：桌面三栏与移动任务视图同时挂载，靠 `min-[1100px]:hidden` / `hidden min-[1100px]:grid` 切换。代价是多挂一份卡片组件；收益是两套版式可以各自排信息优先级，而不用在一个 `grid` 里塞满条件类。`display:none` 的那一份不进无障碍树。
6. **没有新增 CSS 文件、没有改 `src/styles/`**：所有新版式都是 Tailwind 原子类 + 任意值引用令牌（如 `text-[length:var(--fs-body)]`、`bg-[var(--plate-1)]`）。字号只从 `--fs-*` 取，个别地方按既有做法用 `calc(var(--fs-kpi) * 0.8)` 在中栏压 KPI，避免四格表头在 640px 宽的中栏里换行。
7. **顶栏与 `.mnav` 仍是 36px**：它们是另外五个路由共用的外壳，按「不影响其它路由」的约束没有动；训练场自己的操作已经全部 ≥44px。
