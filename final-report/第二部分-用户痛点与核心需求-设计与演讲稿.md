## 1. 结构与论据定位

第二幕的核心任务是**让评委感同身受地理解“为什么市面上现有工具都不好使”**。
通过严谨拆解**两类真实目标用户**，并将现有四类方案（AI 投顾/分析框架、公开竞技场、传统量化、普通模拟盘）的硬伤一一剥开，让评委自然得出结论：**“确实严重断层，中间必须有一个专门的试炼与调优产品！”**

## 2. 页面与视觉物料设计（Slide 3 / 4 / 5）

### Slide 3｜目标用户画像：我们究竟为谁而造？（Who We Build For）
- **左右分栏双画像**：
  1. **画像 A · 有投资经验、缺工程底座的进阶投资者 / 独立研究员（The Discretionary Trader）**
     - **痛点特征**：自己懂选股、懂看盘，有明确的止损和仓位思路，也在用 AI 看资讯；想把自己的思路变成一个专属 AI 助手，但**不会写复杂的量化回测代码**。
     - **核心诉求**：提供开箱即用的框架，用户出投资经验，平台出工程底座。
  2. **画像 B · 已有成熟 Agent 的量化玩家 / 开发者（The Agent Builder）**
     - **痛点特征**：手里已经跑着基于 TradingAgents、Codex、Kimi 或 Claude 构建的现成 Agent；不想为了一个平台放弃已有的工作流。
     - **核心诉求**：零迁移成本，带着自己的 Agent 原样进场，在真实的 A 股环境里跑测试、看真实表现。
- **两个群体的共同灵魂拷问**：
  > “我配置好的这套策略，如果真拿真金白银进 A 股，到底赚不赚钱？亏了到底该改哪？”

### Slide 5｜破局之桥：用户真正需要的四大核心诉求（What Users Actually Need）
- **四大基石图标化排版**：
  1. **进得来（Zero-Migration Onboarding）**：
     - 开箱即用模板（低门槛捏策略） + 标准化协议开放接入（现成 Agent 原样进场）。
  2. **测得真（Realistic A-Share Environment + Human-in-the-Loop）**：
     - 严守真实 A 股制度（T+1、涨跌停、整手、真实税费），并原生支持**人机协同审批与改单**（还原“AI 辅助人决策”的真实实战）。
  3. **改得动（Glass-Box Traceability & Iterative Tuning）**：
     - 每一笔盈亏都能倒查回当时的资讯证据与推理细节；改完一个变量，能在一模一样的历史市场切片下一键重跑对比。
  4. **信得过（Contamination-Resistant & Honest Guardrails）**：
     - 底层防作弊（时点硬截断、防偷看未来新闻）+ 人机双轨独立留痕 + 样本不足拒绝强行排名的诚实底座。

## 3. 中文逐字演播口播稿（约 3 分钟）

> **【演播状态指引】**：语气逐渐转向尖锐、深刻。带领评委从刚才的“全网狂欢”迅速跌落到“真实残酷的痛点现实”，在逻辑上层层逼进。

### 【Slide 3 目标画像：明确受众】（约 40 秒）

“承接刚才的背景，当我们决定做这款产品时，首先思考的是：我们到底在为谁解决问题？

我们的目标用户非常聚焦，主要有两类：

第一类，是**有投资经验、但缺乏工程背景的进阶投资者或独立研究员**。他们自己懂基本面、懂技术分析、有成熟的风控纪律，也在日常用 AI 辅助看盘。他们非常渴望把自己的投资思想变成一个专属的交易 Agent，但他们不会、也不应该去从零写一套复杂的量化回测框架。

第二类，是**手里已经跑着现成 Agent 的开发者与进阶玩家**。他们手里已经在日常用 TradingAgents、Codex、Kimi 或者 Claude 搭建了交易流程。他们不想为了测个试，就把自己顺手的工具推倒重来。

但是，当这两类用户想要把自己的 Agent 真正用到 A 股时，他们却共同撞上了一堵高墙。”

---

### 【Slide 4 断层矩阵：剥开现有方案的四层硬伤】（约 100 秒）

“老师请看这张对比表。市面上现有的方案看似琳琅满目，但真正放到实战里，全部卡在半路：

*(手势指向第一列)*  
第一类是**大众 AI 投顾和开源分析框架**，比如问财、Kimi，或者 TradingAgents 的默认形态。它们分析起行业热点来口若悬河，多空双方辩论得天花乱坠。但它们的致命问题是：**只管给观点，不管算实战总账！**  
如果真按它的建议去买卖——在真实的 A 股里，今天买入当天不能卖，这是 T+1；遇到一字涨停买不进、跌停卖不出；还要扣除千分之五的印花税和交易佣金。把这些真实制度全算进去，它到底赚钱还是亏钱？最大回撤是多少？根本没人替用户算清楚。

*(手势指向第二列)*  
第二类是**公开的 AI 交易竞技场**，比如海外知名的 TradeRank 和 Alpha Arena。它们官方挑了十几个闭源大模型，在黑盒里打擂台晒收益。但问题是：**普通用户只能当观众看戏，完全无法服务自己！**  
首先它们不开放代码，用户带不进自己的 Agent；其次它们测的大多是加密货币和美股，根本不支持 A 股制度；最关键的是，它们全是纯 AI 全自动运行，而真实投资者使用 AI，永远是‘AI 给建议，人来最终把关’。看别人测裸模型，对用户没有任何实战指导价值。

*(手势指向第三列)*  
第三类是**传统量化回测平台**，比如聚宽、JoinQuant、Lean。它们的账本确实严谨，但问题是：**只认死代码，装不下活 Agent！**  
它们逼着用户把交易逻辑写成生硬的 Python 数学公式，把绝大多数懂投资的人挡在门外；更无法承载‘大模型自主去搜新闻、读公告、多轮推理决策’的新型 Agent 范式。

*(手势指向第四列)*  
第四类是**券商软件里的普通模拟炒股**。它们虽然能模拟买卖，但**只记交割流水，不记决策脑回路！**  
亏了钱，账户里只留下一行冷冰冰的成交记录。用户根本查不到当时 Agent 看了哪篇新闻、调了什么工具、为什么做出买入决定。复盘全靠瞎猜，用户根本不知道下一步该改提示词、改模型、还是收紧风控。”

---

### 【Slide 5 四大核心需求：引出破局之桥】（约 40 秒）

“正因为市面上所有的路都走不通，真实用户的需求变得前所未有的清晰。要真正帮到投资者，一套合格的设施必须同时满足四件事：

第一，**进得来**：小白改提示词就能搭，进阶玩家带着现成的 TradingAgents 或 Codex 也能零迁移原样接入；  
第二，**测得真**：账本必须严格遵循 A 股 T+1、涨跌停与税费规则，并且原生支持**人机协同审批与改单**；  
第三，**改得动**：全量保留思考与证据链，亏钱能倒查根因，改完配置能在完全相同的历史切片下重跑对比；  
第四，**信得过**：在底层彻底切断未来信息的泄漏，拒绝把人工改单功劳算给 AI，更不拿运气当实力。

这就是用户梦寐以求的理想工具。

而这也正是我们在过去两个月里，全力倾注打造的系统 —— **openOutcry**。”
