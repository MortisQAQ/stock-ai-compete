# 第二部分 PPT · 制作说明

> 产物：`index.html`（单文件，双击即可放映；不依赖网络）
> 风格：瑞士国际主义 · IKB 克莱因蓝（`data-theme="ikb"`）
> 时长：7 页 / 计划 2.2 分钟（讲稿目标 2.5 分钟，留 12% 缓冲）

## 一、页面计划

| # | data-layout | 版式 | 页面主张 | 对应讲稿 |
|---|---|---|---|---|
| 01 | SWISS-COVER-ASCII | IKB 满屏 + ASCII 呼吸场 | 谁被卡住，需要什么。 | 幕首定调 |
| 02 | S03 | 分屏陈述（42/58 分栏 + 场景对照图） | 一次对，不等于可信。 | 片段一 · 场景 |
| 03 | S08 | 双轨对照（深色 + 方块列表） | 两类人，两个卡点。 | 片段二 · 两类用户 |
| 04 | S16 | 多卡对照（2×2 灰卡 + 21:9 断层图 + 单焦点蓝卡） | 工具不缺，过程是断的。 | 片段三 · 工具断层 |
| 05 | S19 | 四列均分卡（几何图标 + 验收闭环条） | 把困惑，变成四项要求。 | 片段四 · 四项需求 |
| 06 | S12 | 宣言 + 通栏 ink 条（+ 16:10 能力对照图） | 不是再造一个荐股的 AI。 | 片段四 · 结论句 |
| 07 | S10 | 收束分屏（42/58 分栏：左 IKB / 右白底大编号） | 交给系统设计。 | 交棒第三部分 |

主题节奏：accent → light → **dark** → light → light → **ink 通栏** → accent 半屏。
首尾两页都是 IKB，形成色彩闭环；第 03 页用全黑制造呼吸。

## 二、为什么这么排

- **先给一个人，再给两类人。** 02 页只讲一个人的困惑，03 页才把镜头拉开到两类用户，
  避免一上来就抛用户画像。03 页放在深色底，是全场的情绪转折点。
- **04 页改用 `S16` 多卡对照 + 21:9 验证链断层图（`images/04-tool-gap-21x9.png`）。** 左侧 2×2 均质灰卡分别交代“金融 AI 助手 / 量化框架 / 模拟交易 / 公开评测”各自成立的能力与面向个人 Agent 的缺口，右侧以 21:9 断层示意图接唯一一块 IKB 单焦点蓝卡点出 `05 · 你的 Agent`。既承认现状，又把问题定位在“过程不连贯”上，与讲稿“我们关注的不是现有工具都做不到”完全对齐。
- **02 / 06 页补入瑞士风概念配图并避让底部导航圆点。** 02 页在右半灰底置入 `images/02-scenario-one-call.png`（“单日推荐 ✓”与“连续试炼 ?”），06 页在右上置入 `images/06-eval-vs-picker.png`（“再造荐股 AI ✕”与“持续评估能力”三连判断），均采用 `#fafaf8 / #0a0a0a / #002FA7` 严格直角栅格语言。02 页与 07 页的分屏比例统一调整为 `42% / 58%`，让底部居中的 7 个导航点完全落在浅色半屏内，避免骑跨中缝。
- **05 页只讲需求，不讲实现。** 四列等权灰底卡片搭配内联几何线框图标与“验收要点”脚标，并在下方以“01 接入 → 02 试炼 → 03 理解 → 04 比较”验收闭环条收拢底部留白，无单卡偏重。
- **06 页是全场的价值观句。** 大字反向定位 + 能力对照图 + 底部黑通栏承接三个判断（表现如何 / 为什么这样 / 怎么改进），把抽象需求压成三个可记住的词。
- **07 页明确边界。** 第二条 takeaway 直接写明"技术路径与完成度留给第三、四部分"，
  防止答辩时被追问越界。

## 三、内容边界

本部分**只谈用户与需求**，不出现任何架构、模块、技术选型或实现细节——
那些属于第三部分。页面里没有编造任何数字：四项需求、两类用户都来自讲稿的定性描述，
因此没有使用 S06/S07/S21 这类数据专用版式。

## 四、重建方式

```bash
node _build.mjs          # → index.html
node _build.mjs out.html # → 指定输出
```

构建脚本做的事：替换标题 → 注入页面片段 → 注入演讲备注 → 追加 `_deck-extra.css` →
内联 Motion One（断网也能播入场动效）→ 字体非阻塞加载 → 修演讲者预览 iframe 视口。

源文件：

- `_slides.partial.html` 页面结构（7 个 section）
- `_deck-extra.css` 本 deck 的版式扩展与中文字号（不写死颜色，只用语义变量）
- `_notes.partial.js` 演讲备注（按 `data-slide-id` 存储，重排页面不串页）

## 五、校验

```bash
node <SKILL>/scripts/validate-swiss-deck.mjs index.html
node <SKILL>/scripts/validate-presenter-mode.mjs index.html --target-minutes 2.5
```

当前结果：Swiss 静态校验 7 页通过；演讲者校验 7 页 / 7 条备注 / 2.2 分钟 / 0 错误。
渲染实测（1600×900）：无溢出、无内容压到分页安全线、最小字号 16–18px。

## 六、放映须知

- 键盘 `← →` 翻页，`ESC` 总览，`P` 演讲者视图，`B` 切低功耗（停动画/背景）。
- 演讲者视图里的备注可当场改，按页面 ID 保存，不会因为翻页顺序变化而错位。
- 断网可用：字体走本地兜底，入场动效已内联。
