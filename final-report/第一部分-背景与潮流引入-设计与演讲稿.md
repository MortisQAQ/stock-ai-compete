### Slide 05｜供给侧结构性断层：闭源竞品的“训练结果不可见”困局
- **版式**：`S13 · Three Forces`（左 5/16 深墨色宣言块 `.card-ink` 立住核心判断；右 11/16 三张横排卡片剖析现有三类供给——前两张 `.card-fill` 灰底呈现闭源产品盲区，第三张 `.card-accent` 克莱因蓝点出 C 端产品化缺口）
- **左侧深墨宣言块（`.card-ink`）**：
  - 标签：`SUPPLY-SIDE DIAGNOSIS`
  - 主判断：**不是工具不好用，<br/>而是训练结果<br/>在黑盒里不可见。**
  - 底注：现有产品交付的是“单点观点”或“官方秀场”，唯独缺少面向 C 端用户自家 Agent 的透明试炼账本。
- **右侧三张供给剖析卡**：
  - **`01` 闭源投研助手（问财 / Kimi / OpenAI）** `[.card-fill]`：强在单轮问答与深度报告，但**没有连续账户状态与撮合账本**——一句“建议关注”说完即止，用户完全看不见连续持仓后的真实盈亏与风控后果。
  - **`02` 闭源官方竞技榜单（Alpha Arena 等）** `[.card-fill]`：好看、有话题度，但**测试环境与参赛席位对 C 端封闭**——只能看官方预设模型跑分，既接不进用户自己的 Agent，也看不见个人调参后的训练变化。
  - **`03` 开源框架与传统量化回测（TradingAgents 等）** `[.card-accent 唯一焦点]`：代码虽开源，却**缺乏面向 C 端的免基建试炼台与白盒归因界面**——普通投资者既难自建防前视污染的 A 股撮合环境，也无法从回测数字倒查回具体的工具证据与决策漏洞。

#### 🎙️ 现场演讲稿（约 30 秒｜约 130 字）
> 这恰恰暴露了当前供给侧最核心的结构性断层：**不是市面上的工具没用，而是闭源竞品的训练与试炼结果，对普通用户是不可见的。**
> 请看右侧这三类主流供给：第一类，像问财、Kimi 这样的闭源投研助手，给完单次观点就结束了，背后根本没有连续账户账本，你看不见持仓演化的结果；第二类，像 Alpha Arena 这类闭源官方榜单，本质是预设模型的封闭秀场，C 端用户既挂不进自己的 Agent，也看不见自己改完提示词后的训练对比；至于第三类开源代码框架，又把搭环境、接行情、对齐 A 股制度的门槛全甩给了用户，普通投资者根本跑不起来。

## 三、演讲把控与排练检查清单

1. **时间总控**：6 页合计约 **144 秒（2 分 24 秒）**，平均每页停留 22–28 秒，符合瑞士国际主义快节奏、强视觉锚点的演示呼吸感，不会侵占后续产品架构与实机 Demo 的核心时长。
2. **措辞红线自查**：
   - ✅ 全程不贬低现有竞品，不出现“所有工具瞬间哑火/彻底失效”等绝对化夸张句式；
   - ✅ 始终站在 **投资者与 Agent 使用者的 ToC 产品视角**，核心矛盾锁定为 **“闭源竞品训练/试炼结果不可见”**；
   - ✅ 不把学术论文式的“LLM 预训练语料记忆化/开卷考”当作第一立项痛点喧宾夺主（时点截断与 A 股制度约束作为保障试炼结果真实可信的底座自然融入）。
3. **演讲者模式（Presenter Mode）使用方式**：打开 `slides-part1-swiss/index.html` 后按键盘 `P` 键即可进入双屏演讲者控制台，内置与本稿完全对齐的逐页提词要点（讲述要点 / 转场 / 舞台提示）、分组倒计时与下一张 16:9 预览。按 `ESC` 进入总览，`←/→` 翻页，`B` 切换静态/动态。
